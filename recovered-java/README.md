# Recovered Java source

This directory contains JADX-generated Java decompilation of the `com.argusoft` app classes from the supplied TeCHO+ APK. It is reconstructed from DEX bytecode, not the original developer Java source. JADX reported 9 decompilation errors across the APK; this directory is for inspection/reference and is not a standalone Gradle-compilable source set. The original Smali and decoded resources are in `403939_src/`.
